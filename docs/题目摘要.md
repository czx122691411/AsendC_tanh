# TanhCustom 题目摘要

来源：本地保存的“提交考试-Ascend C算子开发能力认证（中级）-昇腾社区”页面。此处只整理要求，未上传包含账号信息的原始 HTML。

- 实现 `TanhCustom`，逐元素计算 `tanh(x) = (exp(x)-exp(-x))/(exp(x)+exp(-x))`。
- 支持 Float16 输入和输出。
- 补齐 kernel 核函数、Tiling 数据成员和 host Tiling 函数。
- 完成 aclnn 调用测试。
- 题面环境要求为昇腾 NPU、CANN 9.0.0，未明确考核后台芯片型号。
- 本次读取的题面未见禁止高阶 Tanh API 的条款，原工程和最新题面仍需核对。
- `op_host` 和 `op_kernel` 内仅修改已有 `.cpp/.h` 文件，不新增多余文件。
- 不修改配套测试工程；最终仅提交算子工程目录 ZIP。

本地模板的 kernel 和 host 仍有 TODO。测试数据生成器使用 Float16、形状 `[8, 2048]`、区间 `[-3, 3)` 随机输入；这些只是现有测试脚本内容，不代表全部隐藏测试约束。
