# TanhCustom 真机构建安装测试：手动复现指导

记录日期：2026-10-22
适用环境：本机 Ascend 910B3、CANN 9.0.0（`~/Ascend/cann-9.0.0`）
配套文档：机制层面的逐步解析见[编译安装流程复盘](编译安装流程复盘.md)；真机精度结论见知识卡 10

本指导对应考题官方流程三阶段：**编译构建 → 安装算子包 → 运行测试工程**，
命令均在本机实际验证通过，可直接复制执行。

---

source ~/Ascend/cann-9.0.0/set_env.sh

## 失败判据对照表

| 报错 | 原因 | 处置 |
| --- | --- | --- |
| `please set env` | 未加载 CANN 环境 | 执行 0.1 后重跑 |
| `FileNotFoundError: './input/input_x.bin'` | 漏了 3.2 的 mkdir | `mkdir -p input output` 后重跑 |
| `ERROR: generate input data failed!` | 同上（首个异常点是 run.sh 开头两条 `rm` 失败） | 同上 |
| `acl executable run failed` | 算子没装上/没被发现 | 检查阶段 2 是否 `SUCCESS`；重新执行 `.run` 安装 |
| 精度 FAIL（`[ERROR] result error`） | kernel 数值问题 | 保留 `output/output_z.bin` 分析误差分布 |

  阶段 3 的最终 PASS 段；每段一张或一张长图。截图中保留命令行提示符

  每次误差具体值略有不同，但结论稳定在 1e-3 容差内，PASS 可复现。

## 补充说明

1. 阶段 2 重复安装是**幂等**的（`.run` 自带 upgrade 逻辑）：
   修改 kernel 代码后重新 `bash build.sh` + 安装即覆盖旧版，无需卸载。
2. 阶段 1 每次都是全量重编（`build.sh` 会 `rm -rf build_out`），
   干净但稍慢；测试工程 `run.sh` 同样每轮 `rm -rf build` 重编调用端。
3. 隐含前提备忘：
   - `ascend-toolkit/latest` 软链必须指向 CANN 9.0.0（`run.sh` 用它找 `setenv.bash`）；
   - kernel 编译目标 `ascend910b`（`CMakePresets.json`），本机 910B3 实测兼容。
