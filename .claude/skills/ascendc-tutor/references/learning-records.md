# 学习记录模板

仅在调试收尾、阶段复盘或恢复学习进度时读取。记录真实结果，内容少时合并字段；不为填表补造事实。

## 调试经验卡

- 问题与日期：
- 验证层级、主机环境与代码版本：
- 最小复现输入/命令，预期与实际：
- 关键证据（文件/日志位置，必要的短摘录）：
- 假设及验证实验；哪些已排除：
- 根因与确认依据（或“暂定”）：
- 最小修复及原失败用例/相关用例的回归结果：
- 下次优先检查什么：

## 阶段检查点

- 当前目标与最后一个已验证步骤：
- 学习者已能解释什么；仍不确定什么：
- 实际环境、路径、代码版本：
- 做了哪些改动，在哪一层验证，证据在哪里：
- 未解决问题与下一步最小实验：
- 当前由谁执行；已有操作授权范围：

## 性能对照（仅做优化时）

- 硬件/CANN/构建条件、输入形状与类型：
- 测量对象：kernel / 调用链 / 端到端；预热和重复次数：
- 基线版本与测量分布：
- 唯一主要改动、预期机制：
- 正确性回归与新测量结果：
- 是否保留，依据及尚未排除的干扰：

写入获授权时，优先沿用现有记录目录；没有约定时使用项目根目录 `docs/learning/`。移除凭据、设备码等无关敏感信息；不得修改原题测试或把记录放入 `op_host`、`op_kernel`。
